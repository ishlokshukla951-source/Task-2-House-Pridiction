# QSkill Internship – Task 2: House Price Prediction

## Objective
Build a Linear Regression model to predict house prices.

## Dataset
This package follows the feature/target structure of Kaggle's **House Prices – Advanced Regression Techniques** dataset, where `SalePrice` is the target. A compact self-contained CSV is included so the notebook runs without an extra download.

## Features
OverallQual, GrLivArea, GarageCars, TotalBsmtSF, FullBath, YearBuilt

## Target
SalePrice

## Tools
Python, Pandas, NumPy, Matplotlib, Scikit-learn

## Workflow
Load data → inspect → split → train Linear Regression → evaluate with MAE/RMSE/R² → visualize → predict.

## Kaggle Source
https://www.kaggle.com/c/5407/data
